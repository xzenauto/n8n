# Guía de Edición — "Nueva normativa para viajar con menores en México"
**Formato:** Vertical (TikTok / Reels / Shorts) · **Duración:** ~38 segundos

---

## 🎨 Lenguaje visual (úsalo en todo el video)

| Elemento | Regla |
|---|---|
| Color **AMARILLO** | Palabras de acción / requisito: `OBLIGATORIO`, `DEBES LLEVAR`, `NUEVA LEY` |
| Color **ROJO** | Advertencias / consecuencias: `CUIDADO`, `TE LO PUEDEN NEGAR`, `MULTA`, `CARTA NOTARIADA` |
| Tipografía | Bold, sans-serif grueso (Montserrat/Poppins Black), mayúsculas en keywords |
| Íconos | ✈️ avión · 📄 documento · ⚠️ advertencia · 🧳 maleta · 👨‍👩‍👧 familia |
| Zoom | Jump cut + zoom-in (5-10%) cada vez que cambias de idea o lanzas una palabra clave |
| SFX recurrentes | **Pop** (aparece ícono) · **Swoosh** (cambia de lista) · **Alerta/ding** (dato importante) · **Pop-up** (aparece texto grande) |

## ✂️ Notas rápidas de ritmo

- **Cadencia de cortes:** uno cada 2-4 segundos como máximo; en los checklists (0:11-0:15 y 0:21-0:26) sube la frecuencia a un corte por ítem para generar dinamismo.
- **Jerarquía de color:** amarillo = "hazlo", rojo = "cuidado/consecuencia". No mezcles ambos en la misma palabra.
- **Primeros 3 segundos:** son el gancho (hook); si se pierden, se pierde el video. Por eso llevan el zoom más agresivo y el SFX de alerta desde el segundo 0.
- **Exportación:** 1080×1920 (9:16), subtítulos quemados (muchos ven sin audio), tipografía mínima 44-50px para que se lea en móvil.
